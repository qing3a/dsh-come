纯净卸载 dsh

停止引擎并执行 npm uninstall -g @deepseek-ai/dsh。DSH 伴侣（壳）保留，不受影响。勾选要一并清理的内容：

dsh 程序包 必清
npm 全局包 @deepseek-ai/dsh（这是卸载的主体，始终执行）
dsh 数据目录 谨慎
删除 %USERPROFILE%\.dsh：含登录凭据、配置文件、会话、工作台数据。不可恢复。
PATH 残留命令 谨慎
删除 PATH 中其他 node 全局目录里的 dsh* 命令（如 C:\tools\nodejs）。一般无需清理。
